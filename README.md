# DocFlow

Collaborative real-time document editor built with:

- Spring Boot microservices
- React + TipTap
- WebSockets
- Operational Transformation
- Redis + Kafka
- PostgreSQL + MongoDB
- Docker Compose

## Services

- Eureka Server
- API Gateway
- User Service
- Document Service
- Collaboration Service
- Version Service
- Presence Service
- Export Service
- Notification Service
